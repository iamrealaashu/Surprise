# Nobita Surprise

A small romantic static web page made for Nobita with animated stars, a photo gallery, and a hidden letter.

## Run locally

```bash
npm start
```

Then open http://localhost:3000 in your browser.

If you want to keep it even simpler, you can also open `index.html` directly in a browser.

## Optional music

Add a file named `music.mp3` next to `index.html` to enable the floating music toggle.
