NOBITA — WRITTEN IN THE STARS (SEPARATE FILE VERSION)
====================================================

PROJECT STRUCTURE
- index.html       Page content / structure
- style.css        All website styling and animations
- script.js        Interactive effects, photo constellation, envelope and music controls
- assets/          Nobita's five photographs
- music.mp3        Optional: add your chosen royalty-free or personally licensed music here

RUN LOCALLY
1. Extract the ZIP.
2. Keep index.html, style.css, script.js and the assets folder together.
3. Open index.html in a modern browser.

BACKGROUND MUSIC
Add an MP3 named music.mp3 beside index.html. The floating music button plays/pauses it after a visitor taps.

PUBLISH
Upload the complete extracted folder to Netlify, Vercel, or GitHub Pages.
Do not upload only index.html: the CSS, JS and assets folder are required.
